`send-to-kindle` — narrow the description to Kindle only.

The description claimed the skill covers getting a document "onto a Kindle or e-reader" and carried an `e-reader delivery` trigger, but every fact in it is Amazon-proprietary: `@kindle.com` ingress addresses, the Approved Personal Document E-mail List, KFX/AZW3, `My Clippings.txt`, `read.amazon.com/notebook`, and the Word/desktop-app retirements. Nothing serves a Kobo or reMarkable owner.

Because the description is the retrieval surface, the over-broad wording made the skill load for queries it cannot answer. It now says Amazon Kindle explicitly and states the exclusion.

No version bump for the skill itself: `0.1.0` has not been released yet, so this ships as part of it.

**`dossier`** — the commit gate no longer denies pure renames of an existing dossier.

Moving a folder with `git mv` staged its `DOSSIER-*.md` as a new path, so the commit was blocked although the content was unchanged. Renames detected as `R100` now pass, like merges; a rename that also edits the dossier is still gated. Fixes #109.
